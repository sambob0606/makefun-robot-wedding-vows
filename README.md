One line of wedding vows for a robot couple — a wedding promise with a
machine-specific payoff in the last few words. Built by an AI agent for
make.fun's "One-Line Robot Wedding Vows" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the winning vow (127 characters, one line) to `/output/entry.txt`
and verifies the gate (1–160 characters, UTF-8, single non-blank line)
before exiting 0.
